# 12 — Future Roadmap

This edition intentionally stops before production-scale infrastructure.

Possible later upgrades include:

- user chat history;
- private per-user knowledge files;
- larger/vector-store infrastructure;
- model selection;
- optional online providers;
- richer validation;
- accounts/roles beyond one local admin;
- background generation jobs;
- more artifact formats;
- React or another frontend architecture;
- MCP integrations.

These are future extensions, not hidden requirements of the teaching core.
