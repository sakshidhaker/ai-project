# 11 — Demo Guide

## Chat demo

Use questions that match different knowledge files, then intentionally rephrase them.

Example:

```text
What is RAG?
How does retrieval augmented generation work?
Why do we create embeddings before searching a knowledge base?
```

The important teaching point is that these are natural-language requests, not hardcoded question IDs.

## Creator demo

Example requests:

```text
Create a beginner-friendly report about Flask.
Create a short study guide for supervised learning.
Create a Python basics document with examples.
```

Generate both PDF and DOCX and inspect the contents.

## Admin demo

Use the configured admin account to show that search and deletion are ordinary Python + SQL + Jinja work, not a JavaScript application.
