TITLE: SQL AND SQLITE DATABASES

PURPOSE:
To explain how to store, query, and manage relational data persistently using SQL.

WHAT IS IT?
SQL (Structured Query Language) is the standard language used to talk to relational databases. SQLite is a lightweight, file-based database that understands SQL without requiring a complex server setup.

WHY IS IT USEFUL?
Saving data to simple JSON or TXT files works for small things, but when you have thousands of users, messages, and settings, searching text files is slow and dangerous. Databases let you safely search, connect, and update massive amounts of data instantly.

CORE CONCEPTS:

tables: Grids holding data (like Excel sheets).

rows / columns: Records and fields.

CREATE: Making a new table.

SELECT: Retrieving data.

INSERT: Adding a new row.

UPDATE: Modifying an existing row.

DELETE: Removing a row.

WHERE: Filtering results.

ORDER BY / GROUP BY: Sorting and grouping.

JOIN: Connecting data across two different tables.

primary keys: A unique ID for every row.

foreign keys: A column that links to a primary key in another table.

indexes: Making searches much faster.

transactions: Ensuring a group of operations all succeed, or all fail together.

parameterized queries: Passing variables safely to prevent hackers from breaking your database.

SIMPLE EXPLANATION:
A database is a digital filing cabinet. Tables are the folders. SQL is the language you use to ask the librarian to fetch data.
"SELECT Name FROM Users WHERE Age > 18" means "Librarian, give me the names from the Users folder, but only the adults."

CODE EXAMPLES (SQL Syntax):

Creating a Table:
CREATE TABLE Users (
id INTEGER PRIMARY KEY AUTOINCREMENT,
username TEXT NOT NULL,
email TEXT UNIQUE
);

Inserting and Querying:
INSERT INTO Users (username, email) VALUES ('Alice', 'alice@test.com');
SELECT * FROM Users WHERE username = 'Alice';

CODE EXAMPLES (Python SQLite integration):
import sqlite3

Connect to a file-based database
conn = sqlite3.connect("database.db")
cursor = conn.cursor()

Parameterized Query (SAFE)
username = "Bob"
cursor.execute("SELECT * FROM Users WHERE username = ?", (username,))
user = cursor.fetchone()

conn.close()

COMMON MISTAKES:

SQL Injection: NEVER use Python string formatting to insert variables into SQL (e.g., f"SELECT * FROM Users WHERE name = '{name}'"). Hackers can use this to delete your database. Always use parameterization (?).

Forgetting conn.commit(): When you INSERT or UPDATE data via Python, it won't actually save to the file unless you tell the connection to commit the transaction.

WHEN TO USE:
Use SQLite for local applications, prototypes, testing, and small to medium web apps where you need reliable, relational data storage.

WHEN NOT TO USE:
If you are building a massive application with thousands of users making changes at the exact same millisecond, you should upgrade from SQLite to PostgreSQL or MySQL.

PROJECT CONNECTION:
The AI Creator Engine uses SQLite to securely store user credentials, authorization levels, and persistent chat history so you can resume conversations later.
